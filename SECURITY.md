# Security Policy

## Supported versions

Security fixes are provided for the latest published `1.x` release. Users should update to the latest release before reporting an issue.

| Version | Supported |
| --- | --- |
| Latest `1.x` release | Yes |
| Earlier releases | No |

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, contact the repository maintainer privately through GitHub to arrange a secure report.

Please include the affected release, Windows version, steps to reproduce, and any relevant logs or screenshots. Do not attach private recordings or other sensitive audio. The maintainer will acknowledge the report and coordinate any fix or disclosure directly with the reporter.
