# SL.STUDIO v1.0.3

**A Windows recorder release focused on clearer setup, improved app identity, and safer distribution.**

## What's new

- **Recognizable Windows app identity:** branded application icon and version details are embedded in the executable.
- **Clearer recording feedback:** stereo peak readings are labeled in dBFS, file size is shown in readable units, and the recording control and folder shortcut include accessible names and helpful tooltips.
- **Better first-run guidance:** the app explains when no default playback endpoint is available and what to connect before recording.
- **More accurate setup and troubleshooting information:** the guide distinguishes WASAPI playback loopback from ASIO physical inputs and explains how to investigate silence, clipping, and buffer warnings.
- **Updated build and dependency tooling:** the Windows build targets .NET 10, the web build uses deterministic dependency installation, and the project dependencies were updated to patched releases.

## Download

- **`SLSTUDIO.exe`** — self-contained, 64-bit Windows desktop application.
- **`SLSTUDIO.exe.sha256`** — SHA-256 checksum for verifying the executable download.

## Capture modes

- **WASAPI loopback** records the default Windows playback endpoint.
- **ASIO input** records the selected physical input channel or pair from an installed ASIO driver. It does not capture audio that another application is playing through its own output path.

Recordings are saved as uncompressed WAV files under the Windows Music known folder in `SL.STUDIO Sets`. Source applications, the Windows mixer, drivers, and audio hardware can affect the captured signal; uncompressed WAV does not mean end-to-end bit-perfect capture.

## Requirements and notes

- 64-bit Windows 10 version 2004 (build 19041) or newer, or Windows 11.
- No separate .NET runtime installation is required for the self-contained executable.
- The executable is not Authenticode-signed. Windows may display an unknown-publisher warning; verify that the file came from the official release and check its SHA-256 checksum before running it.
- For ASIO, the selected driver must expose input channels and may be unavailable while another application is using it.
